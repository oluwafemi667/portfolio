01 / Approach

I build the whole product: the interface, the database, the backend logic and the integrations between them.

Most of my work is Next.js, TypeScript and Supabase. I use Python for scripts and backend logic, and plain HTML, CSS and JS when a framework would be overkill. I add AI only where it does a job ordinary code can't, and I pick the model that fits the project and its budget.

I care about the unglamorous parts: data models that don't break, integrations that fail gracefully, and apps that still work on a bad connection. I'm based in Nigeria, part of the FUTA Techies engineering community, and open to freelance projects.

      01

      Farmledger

      Farm management that keeps working when the signal drops.

      A farm management web app built for a layer farm, designed to keep working when the connection doesn't. Farmhands log eggs, feed, deaths, vaccinations and sick birds on their phones. Entries save on the device and sync later without duplicates. Owners get alerts, flocks, vaccine schedules, stock, sales, invoices and profit per flock in one place.

      • Each entry gets an ID on the device and the server ignores repeats, so a retry never records it twice
      • Access rules in the database (Row Level Security), an append-only audit trail and two-step verification for owners
      • 135 unit tests and 134 database checks

      02

      PayFlow AI

      AI-parsed invoicing, built on a real payment rail.

      A solo-built invoicing product for the DevCareer x Nomba hackathon. Gemini turns a plain-language description into a structured invoice; Nomba's Checkout API handles the money. The interesting part wasn't the happy path. It was diagnosing a silent webhook failure down to Nomba provisioning virtual accounts under the parent account instead of the sub-account, then shipping a transactions-API fallback so payment status stayed reliable while that got resolved upstream.

      • OAuth2 + HMAC-SHA256 webhook verification
      • Fallback reconciliation via polling when webhooks are unreliable
      • Supabase auth with row-level security
