01 / Approach

I work across the full stack, not one slice of it: interface, data layer, backend logic, and the third-party integrations that connect them. AI is one tool in that stack, not the whole identity.

Day to day that's often Next.js, TypeScript, and Supabase, but the toolset shifts with the project: Python for scripting and backend logic, plain HTML/CSS/JS when a framework would be overkill, Gemini brought in only where reasoning genuinely helps. The work below is a sample, not the ceiling, and the underlying skill set, building interfaces that hold up, data models that don't break, and integrations that fail gracefully, applies regardless of which language or framework the job calls for.

Based in Nigeria, working with the FUTA Techies engineering community, and building toward freelance partnerships where that same under-the-hood rigor is the actual product.

02 / Selected Work

A sample of that range in practice, different domains, same underlying approach to frontend, data, and integration work.

01

PayFlow AI

AI-parsed invoicing, built on a real payment rail.

A solo-built invoicing product for the DevCareer x Nomba hackathon. Gemini turns a plain-language description into a structured invoice; Nomba's Checkout API handles the money. The interesting part wasn't the happy path. It was diagnosing a silent webhook failure down to Nomba provisioning virtual accounts under the parent account instead of the sub-account, then shipping a transactions-API fallback so payment status stayed reliable while that got resolved upstream.

  • OAuth2 + HMAC-SHA256 webhook verification
  • Fallback reconciliation via polling when webhooks are unreliable
  • Supabase auth with row-level security
